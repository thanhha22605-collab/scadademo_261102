# TotalParking SCADA Demo

Giao diện mô phỏng giám sát và vận hành hệ thống bãi đỗ xe tự động.

## Xem bản demo

[Mở giao diện SCADA trên GitHub Pages](https://thanhha22605-collab.github.io/scadademo_261102/)

## Chạy trên máy

```bash
npm install
npm run dev
```

Mở `http://localhost:3000`.

## Kiểm tra và build

```bash
npm run check
npm run build
npm run build:pages
```

`npm run build:pages` tạo phiên bản tĩnh dành cho GitHub Pages. Dữ liệu trên
bản demo mặc định chạy ở chế độ mô phỏng và không gửi lệnh tới PLC thực tế.
